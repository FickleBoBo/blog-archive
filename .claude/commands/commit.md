문제 번호를 받아 Algorithm 레포와 블로그 레포에 각각 커밋한다.
인자가 없으면 `_drafts/`의 모든 포스트를 각 문제별로 개별 커밋한다.

**주의: 이 스킬은 사용자의 명시적 허락 없이 실행해서는 안 된다.** 리뷰 통과 등의 상황에서도 사용자가 직접 `/commit`을 호출하거나 커밋을 지시할 때만 실행한다.

## 절차

1. 커밋 스크립트를 실행한다 (드래프트 이동 + 체크리스트 갱신 + 양쪽 레포 커밋):

```
python3 tools/commit.py $ARGUMENTS
```

스크립트 실행 결과를 보고한다. push는 하지 않는다.

2. 스크립트 완료 후 **레포별 커밋 결과 표**를 작성한다:

```
| # | 문제 | Algorithm 레포 | Blog 레포 |
|---|------|---------------|-----------|
| 1 | 2920 음계 | ✅ 새 커밋 | ✅ 새 커밋 |
| 2 | 10189 Hook | - | - |
```
