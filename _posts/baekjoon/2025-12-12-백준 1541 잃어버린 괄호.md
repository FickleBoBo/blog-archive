## 1. 아이디어

숫자와 `+`, `-` 기호로만 이루어진 식에 적절한 괄호를 쳐서 식의 값이 최소가 되게 만드는 문제로 식의 값이 최소가 되게 하려면 `+` 기호를 괄호를 통해 최대한 `-` 기호로 바꿔줘야 한다. 포인트는 한번만 `-` 기호가 등장하면 그 뒤의 모든 `+` 기호를 괄호를 통해 `-` 기호로 바꿀 수 있다는 것으로 `-` 기호가 등장한 이후로 등장한 숫자는 모두 빼주기만 하면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

`StringTokenizer`를 통해 파싱하는 방식으로 해결했는데 `-` 기호를 기준으로 파싱한 후 첫 토큰의 식의 합에서 나머지 토큰의 식의 합을 빼주었다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine(), "-");

        int ans = sum(st.nextToken());
        while (st.hasMoreTokens()) {
            ans -= sum(st.nextToken());
        }

        System.out.println(ans);
    }

    static int sum(String token) {
        StringTokenizer st = new StringTokenizer(token, "+");

        int sum = 0;
        while (st.hasMoreTokens()) {
            sum += Integer.parseInt(st.nextToken());
        }

        return sum;
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    int ans = 0;
    int sign = 1;
    int tmp = 0;

    for (char c : s) {
        if (c == '+' || c == '-') {
            ans += tmp * sign;
            tmp = 0;

            if (c == '-') {
                sign = -1;
            }
        } else {
            tmp *= 10;
            tmp += c - '0';
        }
    }
    ans += tmp * sign;

    cout << ans;
}
```
