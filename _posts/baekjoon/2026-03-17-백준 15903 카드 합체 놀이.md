## 1. 아이디어

$n$ 장의 카드들이 주어지며 $m$ 번의 카드 합체를 거쳤을 때, 모든 카드의 숫자의 합이 최소가 되야 한다. $x$ 번 카드와 $y$ 번 카드에 대한 카드 합체는 두 카드의 숫자를 $x + y$ 로 덮어쓰는 것인데, 카드 합체 이전에 두 카드의 합은 $x + y$ 였다가 카드 합체 후에는 $2 \times (x + y)$ 가 된다. 따라서 모든 카드의 숫자의 합이 최소가 되려면 현재 상태에서 가장 숫자가 작은 두 카드를 합치는 과정을 반복하면 되며 우선순위 큐를 활용해 현재 카드들 중 가장 숫자가 작은 두 카드를 뽑고 카드 합체를 한 후 다시 우선순위 큐에 넣는 과정을 반복해서 해결했다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        PriorityQueue<Long> pq = new PriorityQueue<>();
        st = new StringTokenizer(br.readLine());
        while (n-- > 0) {
            pq.offer(Long.parseLong(st.nextToken()));
        }

        while (m-- > 0) {
            long x = pq.poll();
            long y = pq.poll();
            pq.offer(x + y);
            pq.offer(x + y);
        }

        long sum = 0;
        while (!pq.isEmpty()) {
            sum += pq.poll();
        }

        System.out.println(sum);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    priority_queue<long long, vector<long long>, greater<>> pq;
    while (n--) {
        long long x;
        cin >> x;
        pq.push(x);
    }

    while (m--) {
        long long x = pq.top();
        pq.pop();

        long long y = pq.top();
        pq.pop();

        pq.push(x + y);
        pq.push(x + y);
    }

    long long sum = 0;
    while (!pq.empty()) {
        sum += pq.top();
        pq.pop();
    }

    cout << sum;
}
```
