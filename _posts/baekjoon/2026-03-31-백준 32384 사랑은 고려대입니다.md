## 1. 아이디어

반복문을 활용해서 `LoveisKoreaUniversity`를 $N$ 번 출력만 해주면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            System.out.print("LoveisKoreaUniversity ");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    while (n--) {
        cout << "LoveisKoreaUniversity ";
    }
}
```
