## 1. 아이디어

첫 번째 레벨부터 마지막 레벨까지 순서대로 주어지며 각 레벨은 다음 레벨보다 점수가 작아야 한다. 점수를 내리는 것을 최소한으로 하려면 점수를 낮춰야할 경우 다음 레벨보다 1 더 적게하는 것이 최소가 되므로 마지막 레벨의 직전 레벨부터 역순으로 탐색하며 현재 레벨이 다음 레벨보다 점수가 높거나 같으면 다음 레벨보다 1 낮도록 낮추고 내린 값을 저장하는 과정을 반복하면 된다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }

        int ans = 0;
        for (int i = n - 2; i >= 0; i--) {
            if (arr[i] >= arr[i + 1]) {
                ans += arr[i] - arr[i + 1] + 1;
                arr[i] = arr[i + 1] - 1;
            }
        }

        System.out.println(ans);
    }
}
```
