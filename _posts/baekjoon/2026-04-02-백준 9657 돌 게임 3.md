## 1. 아이디어

돌을 1개, 3개 또는 4개 가져갈 수 있는 상황으로 두 플레이어가 서로 최선의 게임을 한다고 가정했으므로 특정 개수의 돌에 대해 반드시 이기거나 지는 두 가지 상태만 존재한다.

해당 문제는 다이나믹 프로그래밍을 활용하면 해결할 수 있는데 dp 테이블은 현재 턴인 플레이어가 `i`개의 돌이 탁자 위에 존재할 때 반드시 이길 수 있으면 `true`, 지면 `false`로 체크하는 dp 테이블을 이용했다. 상근이가 먼저 시작하고 돌을 1개, 3개 또는 4개 가져갈 수 있으므로 `dp[1] = dp[3] = dp[4] = true`가 된다. 탁자 위에 돌이 2개 있을 경우 상근이는 하나를 가져가야하고 남은 하나는 창영이가 가져가서 상근이가 반드시 지게 되므로 `dp[2] = false`다.

dp 점화식은 현재 턴인 플레이어가 상대 플레이어를 반드시 지는 상태로 보낼 수 있으면 현재 반드시 이기는 상태이다. 탁자 위의 돌이 `i`개 있을 때 `dp[i]`는 1개, 3개 또는 4개를 가져간 `dp[i - 1], dp[i - 3], dp[i - 4]`에 대해 상대방이 반드시 지는 상태가 존재하면 되며 이는 셋 중 `false`인 상태가 하나라도 존재하면 된다. 돌을 가져가는 순간 상대 턴으로 바뀌므로 `false`는 상대방이 반드시 지는 개수라는 의미가 된다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        boolean[] dp = new boolean[1001];
        dp[1] = dp[3] = dp[4] = true;
        for (int i = 5; i <= n; i++) {
            if (!dp[i - 1] || !dp[i - 3] || !dp[i - 4]) {
                dp[i] = true;
            }
        }

        if (dp[n]) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```
