## 1. 아이디어

주어진 회의들을 최소의 강의실을 사용해서 모두 진행해야하는 문제로 이는 임의의 특정 시각에 진행 중인 회의의 최대 개수와 동일하다.(수직선 상에 회의들을 배치해보면 쉽게 알 수 있다.) 접근은 우선순위 큐를 활용해서 해결할 수도 있고 스위핑을 활용해서도 해결할 수 있다.

우선순위 큐를 활용할 경우 회의를 시작 시각에 대한 오름차순으로 정렬한 후, 회의의 종료 시각들을 오름차순으로 담는 우선순위 큐를 먼저 선언해줬다. 각 회의에 대해 해당 회의를 진행하는 것을 우선순위 큐에 담는 것으로 보면 우선순위 큐에 담긴 회의의 수가 필요한 강의실의 수가 된다. 이때 종료 시각이 현재 회의의 시작 시각보다 빠르거나 같은 회의가 있으면 해당 회의에 이어서 하면 되므로 해당 회의를 빼고 현재 회의를 넣어주면 되며, 그런 회의가 없으면 그냥 현재 회의를 넣어주면 된다. 우선순위 큐의 크기가 최대가 되는 순간을 찾아야하므로 매번 최대 크기를 갱신해주다가 출력해주면 된다.

스위핑을 활용할 경우 시각과 타입을 활용하면 되는데 시각은 회의의 시작 시각으로 하나, 종료 시각으로 하나를 만들고, 타입은 시작하는 회의는 +1, 종료되는 회의는 -1로 초기화하면 된다. 이후 이 이벤트들을 시각에 대한 오름차순, 시각이 같으면 타입에 대한 오름차순으로 정렬한 후 이벤트들을 쭉 순회하며 타입의 누적합을 구하면 된다. 타입의 누적합이 최대가 되는 순간이 가장 동시에 진행중인 회의가 많은 순간이다.

## 2. 코드

### 1. 우선순위 큐 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[n][2];
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            arr[i][0] = Integer.parseInt(st.nextToken());
            arr[i][1] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr, (o1, o2) -> Integer.compare(o1[0], o2[0]));

        PriorityQueue<Integer> pq = new PriorityQueue<>();
        pq.offer(0);
        int max = 0;
        for (int i = 0; i < n; i++) {
            if (pq.peek() <= arr[i][0]) pq.poll();
            pq.offer(arr[i][1]);

            max = Math.max(max, pq.size());
        }

        System.out.println(max);
    }
}
```

### 2. 우선순위 큐 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<pair<int, int>> v(n);
    for (auto& [s, t] : v) cin >> s >> t;
    sort(v.begin(), v.end());

    priority_queue<int, vector<int>, greater<>> pq;
    pq.push(0);
    int mx = 0;
    for (auto [s, t] : v) {
        if (pq.top() <= s) pq.pop();
        pq.push(t);

        mx = max(mx, (int)pq.size());
    }

    cout << mx;
}
```

### 3. 스위핑 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[n * 2][2];
        for (int i = 0; i < n * 2; i += 2) {
            st = new StringTokenizer(br.readLine());
            arr[i][0] = Integer.parseInt(st.nextToken());
            arr[i][1] = 1;
            arr[i + 1][0] = Integer.parseInt(st.nextToken());
            arr[i + 1][1] = -1;
        }
        Arrays.sort(arr, (o1, o2) -> {
            if (o1[0] != o2[0]) return Integer.compare(o1[0], o2[0]);
            return Integer.compare(o1[1], o2[1]);
        });

        int max = 0;
        int cnt = 0;
        for (int i = 0; i < n * 2; i++) {
            cnt += arr[i][1];
            max = Math.max(max, cnt);
        }

        System.out.println(max);
    }
}
```

### 4. 스위핑 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

pair<int, int> arr[200000 * 2];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    int idx = 0;
    for (int i = 0; i < n; i++) {
        int s, t;
        cin >> s >> t;
        arr[idx++] = {s, 1};
        arr[idx++] = {t, -1};
    }
    sort(arr, arr + n * 2);

    int mx = 0;
    int cnt = 0;
    for (int i = 0; i < n * 2; i++) {
        cnt += arr[i].second;
        mx = max(mx, cnt);
    }

    cout << mx;
}
```

## 3. 리뷰

우선순위 큐 방식의 경우 종료 시각이 0인 더미 회의를 하나 넣으면 우선순위 큐가 비었을 때 예외 처리를 안해도 됐는데 좋은 아이디어였던 것 같다.

스위핑에서 시각에 대해서만 정렬했었는데 동일 시각에선 종료 이벤트를 먼저 처리해야 이전 회의가 끝나자마자 다음 회의가 시작되는 처리가 된다.
