## 1. 아이디어

첫째 줄은 재환이가 가장 길게 낼 수 있는 소리가, 둘째 줄은 의사가 듣기를 원하는 소리가 주어지며 재환이가 가장 길게 낼 수 있는 소리가 의사가 듣기를 원하는 소리보다 짧으면 진단을 내릴 수 없으므로 비교 연산자로 비교만 해주면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s1 = br.readLine();
        String s2 = br.readLine();

        if (s1.length() < s2.length()) {
            System.out.println("no");
        } else {
            System.out.println("go");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s1, s2;
    cin >> s1 >> s2;

    if (s1.size() < s2.size()) {
        cout << "no";
    } else {
        cout << "go";
    }
}
```
