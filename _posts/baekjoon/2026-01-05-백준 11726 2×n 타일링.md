## 1. 아이디어

다이나믹 프로그래밍을 활용해서 해결할 수 있는 전형적인 문제로 dp 테이블은 해당 가로 길이로 만들 수 있는 타일링의 수로 정의하면 된다. `dp[i]`는 가로 길이 `i`인 타일링의 수로 가로 길이 `i`인 타일링들은 가로 길이 `i - 2`인 타일링들에서 1×2 타일을 오른쪽 끝에 붙이거나, 가로 길이 `i - 1`인 타일링들에서 2×1 타일을 오른쪽에 붙이는 경우가 됨을 알 수 있다. 따라서 `dp[i] = dp[i - 2] + dp[i - 1]`로 점화식을 세울 수 있고, `dp[1] = 1`, `dp[2] = 2`임은 간단하게 알 수 있으니 이를 바탕으로 해결하면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {

    static final int MOD = 10007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n == 1) {
            System.out.println(1);
            return;
        }

        int[] dp = new int[1 + n];
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
        }

        System.out.println(dp[n]);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

const int MOD = 10007;
int dp[1001] = {0, 1, 2};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
    }

    cout << dp[n];
}
```
