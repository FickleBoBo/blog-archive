## 1. 아이디어

[BaekJoon 9657번 - 돌 게임 3](/posts/baekjoon-9657) 문제에서 $N$ 의 크기가 매우 커진 문제로 이전처럼 상태 DP를 활용해서는 해결할 수 없다. 이전 문제의 상태 DP를 잘보면 7의 주기로 `L, W, L, W, W, W, W` 처럼 이기는 자리와 지는 자리가 반복되는 것을 알 수 있는데 이를 활용해서 $N$ 을 7로 나눈 나머지가 0 또는 2일 경우 창용이가 승리하며, 나머지의 경우 상근이가 승리하게 됨을 알 수 있다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        if (n % 7 == 0 || n % 7 == 2) {
            System.out.println("CY");
        } else {
            System.out.println("SK");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;

    if (n % 7 == 0 || n % 7 == 2) {
        cout << "CY";
    } else {
        cout << "SK";
    }
}
```
