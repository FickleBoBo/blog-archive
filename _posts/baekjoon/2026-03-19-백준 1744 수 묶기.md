## 1. 아이디어

수열에서 두 수를 묶을 수 있을 때 합의 최댓값을 구해야 하는 문제다. 두 수를 묶었을 때 이전보다 커야 묶는게 유리한데 양수와 양수를 묶으면 묶었을 때 값이 더 커질 수 있고, 음수와 음수를 묶으면 항상 값이 더 커진다. 양수와 음수를 묶으면 항상 값이 더 작아진다. 따라서 주어진 수들을 양수와 음수로 분리해서 우선순위 큐에 담았다. 양수의 경우 남은 양수 중 가장 큰 두 양수를 선택해서 묶었을 때 더 커지는지 안 묶는게 나은지 비교하면 되며, 음수는 가장 작은 수 두 개부터 항상 묶어가면 된다. 입력에서 0도 들어올 수 있는데 0은 양수에 붙이면 항상 안묶어야하고 음수에 붙이면 항상 묶는게 유리하므로 0도 음수쪽에 붙여줬다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        PriorityQueue<Integer> pq = new PriorityQueue<>(Comparator.reverseOrder());
        PriorityQueue<Integer> pq2 = new PriorityQueue<>();
        while (n-- > 0) {
            int x = Integer.parseInt(br.readLine());
            if (x > 0) {
                pq.offer(x);
            } else {
                pq2.offer(x);
            }
        }

        int sum = 0;
        while (pq.size() > 1) {
            int a = pq.poll();
            int b = pq.poll();
            sum += Math.max(a * b, a + b);
        }
        if (!pq.isEmpty()) {
            sum += pq.poll();
        }

        while (pq2.size() > 1) {
            sum += pq2.poll() * pq2.poll();
        }
        if (!pq2.isEmpty()) {
            sum += pq2.poll();
        }

        System.out.println(sum);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    priority_queue<int> pq;
    priority_queue<int, vector<int>, greater<>> pq2;

    int n;
    cin >> n;

    while (n--) {
        int x;
        cin >> x;

        if (x > 0) {
            pq.push(x);
        } else {
            pq2.push(x);
        }
    }

    int sum = 0;
    while (pq.size() > 1) {
        int a = pq.top();
        pq.pop();

        int b = pq.top();
        pq.pop();

        sum += max(a * b, a + b);
    }
    if (!pq.empty()) {
        sum += pq.top();
        pq.pop();
    }

    while (pq2.size() > 1) {
        int a = pq2.top();
        pq2.pop();

        int b = pq2.top();
        pq2.pop();

        sum += a * b;
    }
    if (!pq2.empty()) {
        sum += pq2.top();
        pq2.pop();
    }

    cout << sum;
}
```
