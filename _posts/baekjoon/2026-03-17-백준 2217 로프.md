## 1. 아이디어

특정 로프를 사용했을 때 들어올릴 수 있는 최대 중량은 해당 로프보다 들어올릴 수 있는 중량이 크거나 같은 모든 로프를 사용하면 되며, 이때 들어올릴 수 있는 최대 중량은 가장 들어올릴 수 있는 중량이 작은 로프가 들어올릴 수 있는 최대 중량과 사용한 로프의 수의 곱으로 결정된다. 따라서 로프들을 배열에 담아 오름차순으로 정렬한 후 순회하며 각 로프를 선택했을 때 들어올릴 수 있는 최대 중량을 계산해줬다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }
        Arrays.sort(arr);

        int max = 0;
        for (int i = 0; i < n; i++) {
            max = Math.max(max, arr[i] * (n - i));
        }

        System.out.println(max);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> v(n);
    for (int& x : v) cin >> x;
    sort(v.begin(), v.end());

    int mx = 0;
    for (int i = 0; i < n; i++) {
        mx = max(mx, v[i] * (n - i));
    }

    cout << mx;
}
```
