## 1. 아이디어

돌을 1개 또는 3개를 가져갈 수 있는 상황으로 1과 3은 모두 홀수다. 따라서 탁자 위의 돌에 대해 서로 가져갈 때마다 남은 돌의 홀짝이 계속 바뀌게 되며, 초기 돌이 홀수 개일 경우 창영이는 항상 남은 돌을 짝수 개에서 홀수 개로 바꿀 수밖에 없어서 마지막 돌을 가져갈 일이 없으므로 질 수 없다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n % 2 == 0) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);

    }
}
```
