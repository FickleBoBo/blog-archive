## 1. 아이디어

<br>

42로 나눈 겹치지 않는 나머지의 개수를 구하는 문제로 방문 체크 배열을 활용해서 해결할 수도 있고, 집합 자료구조를 활용해도 해결할 수 있다.

---

## 2. 코드

<br>

### 1. 방문 체크 배열 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        boolean[] vis = new boolean[42];
        for (int i = 0; i < 10; i++) {
            int x = Integer.parseInt(br.readLine());
            vis[x % 42] = true;
        }

        int cnt = 0;
        for (boolean flag : vis) {
            if (flag) cnt++;
        }

        System.out.println(cnt);
    }
}
```

<br>

### 2. 방문 체크 배열 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    vector<bool> vis(42);
    for (int i = 0; i < 10; i++) {
        int x;
        cin >> x;
        vis[x % 42] = true;
    }

    cout << count(vis.begin(), vis.end(), true);
}
```

<br>

### 3. 집합 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        Set<Integer> set = new HashSet<>();
        for (int i = 0; i < 10; i++) {
            int x = Integer.parseInt(br.readLine());
            set.add(x % 42);
        }

        System.out.println(set.size());
    }
}
```

<br>

### 4. 집합 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);

    for (int i = 0; i < 10; i++) {
        int x;
        cin >> x;
        st.insert(x % 42);
    }

    cout << st.size();
}
```
