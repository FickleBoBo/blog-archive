## 1. 아이디어

주어진 알파벳이 `N`이거나 `n`이면 `"Naver D2"`를, 아니라면 `"Naver Whale"`를 조건문으로 분기해서 출력만 해주면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        if (s.equals("N") || s.equals("n")) {
            System.out.println("Naver D2");
        } else {
            System.out.println("Naver Whale");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    if (s == "N" || s == "n") {
        cout << "Naver D2";
    } else {
        cout << "Naver Whale";
    }
}
```
