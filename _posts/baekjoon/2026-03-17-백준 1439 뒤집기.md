## 1. 아이디어

0과 1로만 이루어진 문자열에서 임의 구간의 수를 뒤집는 것으로 전체 숫자를 하나로 통일시켜야 한다. 그리디한 접근법으로 해결할 수 있는데 모든 숫자를 0으로 만드려면 기존의 0은 건드리지 않으면서 모든 1만 뒤집으면 된다. 이때 구간 단위로 뒤집는 횟수를 최소로 해야하므로 1이 포함된 연속된 구간들에 대해 한번에 뒤집어주면 되며, 반대로 모든 숫자를 1로 만들려고 할 때도 마찬가지다. 따라서 주어진 문자열에서 0으로 이어진 구간과 1로 이어진 구간의 개수를 각각 세서 더 적은 쪽을 뒤집어주면 된다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        int cnt0 = 0;
        int cnt1 = 0;
        char prv = '\u0000';

        for (char c : s.toCharArray()) {
            if (c != prv) {
                if (c == '0') {
                    cnt0++;
                } else {
                    cnt1++;
                }
            }

            prv = c;
        }

        System.out.println(Math.min(cnt0, cnt1));
    }
}
```

### 3. StringTokenizer 활용 [Java]

`StringTokenizer`와 `countTokens` 메서드를 활용하면 각 구간의 개수를 훨씬 간단하게 구할 수 있다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        int cnt0 = new StringTokenizer(s, "1").countTokens();
        int cnt1 = new StringTokenizer(s, "0").countTokens();

        System.out.println(Math.min(cnt0, cnt1));
    }
}
```
