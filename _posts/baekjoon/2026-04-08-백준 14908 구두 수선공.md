## 1. 아이디어

하루에 한 작업만 할 수 있을 때 최소 보상금을 지불하는 작업 순서를 구하는 문제로 그리디 알고리즘을 활용하면 해결할 수 있다. 임의의 두 작업 $A$ 와 $B$ 가 있을 때 $A$ 작업을 먼저하고 $B$ 작업을 하는 경우에는 $A$ 의 작업 기간만큼 $B$ 작업을 못하므로 $T_A \times S_B$ 만큼의 보상금을 지불해야 하고, $B$ 작업을 먼저하고 $A$ 작업을 하는 경우에는 $T_B \times S_A$ 만큼의 보상금을 지불해야 한다. 따라서 두 보상금 중 더 적은 보상금을 지불하는 작업을 먼저 하는 것이 이득이다. 이 정렬 기준에 맞춰 작업들을 정렬할 경우의 이를 만족하지 않는 임의의 작업 순서에 대해 두 작업을 골라서 이 정렬 기준에 맞춰 작업 순서를 바꿔 줄 경우 내야 하는 보상금이 항상 적어지거나 같아지므로 교환 논증에 의해 최적임을 알 수 있다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[n][3];
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            int t = Integer.parseInt(st.nextToken());
            int s = Integer.parseInt(st.nextToken());
            arr[i][0] = i + 1;
            arr[i][1] = t;
            arr[i][2] = s;
        }
        Arrays.sort(arr, (o1, o2) -> Integer.compare(o1[1] * o2[2], o2[1] * o1[2]));

        for (int i = 0; i < n; i++) {
            sb.append(arr[i][0]).append(" ");
        }

        System.out.println(sb);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<tuple<int, int, int>> v(n);
    for (int i = 0; i < n; i++) {
        int t, s;
        cin >> t >> s;
        v[i] = {i + 1, t, s};
    }
    stable_sort(v.begin(), v.end(), [](auto& a, auto& b) {
        return get<1>(a) * get<2>(b) < get<1>(b) * get<2>(a);
    });

    for (auto [x, t, s] : v) {
        cout << x << ' ';
    }
}
```
