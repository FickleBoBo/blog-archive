## 1. 아이디어

$1$ 부터 $N$ 까지의 수를 한 번씩 이용해서 길이가 $M$ 인 가장 긴 증가하는 부분 수열, 길이가 $K$ 인 가장 긴 감소하는 부분 수열을 만들 수 있는지 판단하고 만들 수 있다면 실제로 출력도 해야하는 문제다. 해당 문제는 가장 긴 감소하는 부분 수열의 길이를 먼저 맞춰 놓고 이후 가장 긴 증가하는 부분 수열의 길이를 맞춰나가는 방식으로 해결했다.

가장 긴 감소하는 부분 수열의 길이를 맞추는 것은 $1$ 부터 $N$ 까지 $K$ 개 단위로 역순 정렬을 해주는 방식으로 간단하게 만들 수 있다. $N = 13$, $K = 4$ 일 경우 $[4, 3, 2, 1, 8, 7, 6, 5, 12, 11, 10, 9, 13]$ 과 같이 $4$ 개 단위로 역순 정렬을 해주면 가장 긴 감소하는 부분 수열의 길이를 $4$ 로 맞추면서 $1$ 부터 $N$ 까지 모든 수를 사용할 수 있다.

가장 긴 증가하는 부분 수열의 길이를 맞추는 것은 위 수열의 끝에서부터 점점 오름차순으로 재배치를 해주면 된다. 가장 큰 수를 맨 끝에, 그 다음으로 큰 수를 그 앞에 배치하는 식으로 진행하면 가장 긴 증가하는 부분 수열의 길이도 점점 늘릴 수 있다.

위 규칙을 통해 $N$, $M$, $K$ 로 수열을 만들 수 없는 경우도 구할 수 있는데 먼저 $K$ 개 단위 청크와 나머지에 대해 가장 긴 증가하는 부분 수열은 청크의 수보다 짧아질 수는 없다. 청크의 순서를 바꿀 경우 가장 긴 감소하는 부분 수열의 길이가 바뀌게 되며 각 청크마다 가장 큰 수도 다음 청크의 가장 작은 수보다 작으므로 각 청크에서 하나를 뽑아 만든 수열이 가장 긴 증가하는 부분 수열이 된다. 또한 더 길어질 수 없는 최대 길이의 상한도 구할 수 있는데 청크가 최소 하나는 있어야 하므로 $M$ 개의 수를 제외한 $N - K$ 개의 수만 가장 긴 증가하는 부분 수열을 만들기 위한 정렬에 뽑아갈 수 있고 첫 번째 청크의 수 하나도 가장 긴 증가하는 부분 수열의 일부가 되므로 $N - K + 1 < M$ 이면 조건을 만족하는 수열을 만들 수 없다.

## 2. 코드

구현은 $N$ 이 최대 $500$ 이므로 가장 긴 증가하는 부분 수열을 만들기 위해 후보 구간 전체에서 매번 최댓값을 찾는 방식으로 구현했다. 최댓값을 찾았다면 삽입 정렬처럼 원소를 한 칸씩 밀고 삽입을 해주고 후보 구간의 길이를 줄이면 된다.

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        if ((n + k - 1) / k > m || n - k + 1 < m) {
            System.out.println(-1);
            return;
        }

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = i + 1;
        }

        for (int i = 0; i < n; i += k) {
            reverse(arr, i, Math.min(i + k - 1, n - 1));
        }

        int cnt = m - (n + k - 1) / k;
        int right = n - 1;
        while (cnt > 0) {
            int max = 0;
            int idx = 0;
            for (int i = 0; i <= right; i++) {
                if (arr[i] > max) {
                    max = arr[i];
                    idx = i;
                }
            }

            for (int i = idx; i < right; i++) {
                arr[i] = arr[i + 1];
            }
            arr[right] = max;

            if (idx != right) cnt--;
            right--;
        }

        for (int x : arr) {
            sb.append(x).append(" ");
        }

        System.out.println(sb);
    }

    static void reverse(int[] arr, int start, int end) {
        while (start < end) {
            int tmp = arr[start];
            arr[start] = arr[end];
            arr[end] = tmp;
            start++;
            end--;
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m, k;
    cin >> n >> m >> k;

    if ((n + k - 1) / k > m || n - k + 1 < m) {
        cout << -1;
        return 0;
    }

    vector<int> v(n);
    iota(v.begin(), v.end(), 1);

    for (int i = 0; i < n; i += k) {
        reverse(v.begin() + i, v.begin() + min(i + k, n));
    }

    int cnt = m - (n + k - 1) / k;
    int right = n - 1;
    while (cnt > 0) {
        int max = 0;
        int idx = 0;
        for (int i = 0; i <= right; i++) {
            if (v[i] > max) {
                max = v[i];
                idx = i;
            }
        }

        for (int i = idx; i < right; i++) {
            v[i] = v[i + 1];
        }
        v[right] = max;

        if (idx != right) cnt--;
        right--;
    }

    for (int x : v) {
        cout << x << ' ';
    }
}
```
