## 1. 아이디어

$S$ 를 최소로 만드는 문제로 $S$ 는 $A$ 의 특정 원소와 $B$ 의 특정 원소의 곱들의 합으로 이루어졌다. 이를 $B$ 는 각각 숫자들이 적힌 카드라고 보고, $A$ 는 각 카드의 개수로 봐서 전체 카드의 수의 합이 최소가 되게 하는 문제로 생각하면 간단한데, 이러면 숫자가 큰 카드가 최대한 적게 있어야 전체 합이 최소가 된다. 따라서 $B$ 에서 가장 큰 수는 $A$ 에서 가장 작은 수와 매칭시키고, $B$ 에서 두 번째로 큰 수는 $A$ 에서 두 번째로 작은 수와 매칭시키는 방식으로 모든 원소를 매칭시키면 $S$ 값이 최소가 된다. 좀 더 디테일하게는 재배열 부등식에 대해 알면 이런 매칭이 최솟값을 보장하는 것을 알 수 있다.

구현의 경우 $B$ 를 재배열하지 말라고 했지만 어차피 $S$ 의 최솟값만 구하는 상황에서는 의미가 없다. 따라서 $A$ 와 $B$ 를 모두 정렬하고 $S$ 의 최솟값을 계산해나가는 방식으로 해결했다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());

        int[] a = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            a[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(a);

        int[] b = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            b[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(b);

        int s = 0;
        for (int i = 0; i < n; i++) {
            s += a[i] * b[n - 1 - i];
        }

        System.out.println(s);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> a(n);
    for (int& x : a) cin >> x;
    sort(a.begin(), a.end());

    vector<int> b(n);
    for (int& x : b) cin >> x;
    sort(b.rbegin(), b.rend());

    int s = 0;
    for (int i = 0; i < n; i++) {
        s += a[i] * b[i];
    }

    cout << s;
}
```
