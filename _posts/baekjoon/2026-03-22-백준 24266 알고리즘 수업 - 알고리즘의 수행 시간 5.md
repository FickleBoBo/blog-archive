## 1. 아이디어

MenOfPassion 알고리즘은 $1$ 부터 $n$ 까지 반복하는 `for` 문이 3중첩 되어있는 형태로 `코드1`은 $n^3$ 번 실행되게 된다. 따라서 수행 횟수는 $n^3$ 번이 되며, 시간 복잡도가 $O(N^3)$ 이어서 최고차항의 차수는 $3$ 이 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * n * n);
        System.out.println(3);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * n * n << '\n';
    cout << 3;
}
```
