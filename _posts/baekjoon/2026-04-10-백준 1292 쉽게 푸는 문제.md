## 1. 아이디어

$1$ 은 한 개, $2$ 는 두 개, $3$ 은 세 개가 나란히 오는 식으로 주어진 수열에서 일정한 구간의 합을 구하는 문제로 수열을 규칙에 맞춰 생성한 후 합을 구하는 방식으로 해결했다. 수열에 적을 수와 위치를 각각 변수로 설정한 후 반복문을 통해 적을 위치부터 적을 수만큼 연달아 수를 적어서 주어진 조건을 만족하는 수열을 생성하고 합을 구해줬다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int[] arr = new int[1001];
        int num = 1;
        int idx = 1;

        out:
        while (true) {
            for (int i = 1; i <= num; i++) {
                arr[idx++] = num;
                if (idx > 1000) break out;
            }
            num++;
        }

        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());

        int sum = 0;
        for (int i = a; i <= b; i++) {
            sum += arr[i];
        }

        System.out.println(sum);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int arr[1001];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int num = 1;
    int idx = 1;
    bool flag = true;

    while (flag) {
        for (int i = 1; i <= num; i++) {
            arr[idx++] = num;
            if (idx > 1000) {
                flag = false;
                break;
            }
        }
        num++;
    }

    int a, b;
    cin >> a >> b;

    int sum = 0;
    for (int i = a; i <= b; i++) {
        sum += arr[i];
    }

    cout << sum;
}
```
