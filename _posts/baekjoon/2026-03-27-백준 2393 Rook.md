## 1. 아이디어

여러 특수문자로 이루어진 룩을 출력하는 문제로 이스케이프해야 하는 문자가 섞여 있음에 주의해야 한다.

---

## 2. 코드

### 1. 풀이 [Java]

룩을 이루는 문자 중 이스케이프 처리가 필요한 문자로 역슬래시(`\`)가 있어서 앞에 역슬래시를 붙여 이스케이프 처리만 추가해줬다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("  ___  ___  ___");
        System.out.println("  | |__| |__| |");
        System.out.println("  |           |");
        System.out.println("   \\_________/");
        System.out.println("    \\_______/");
        System.out.println("     |     |");
        System.out.println("     |     |");
        System.out.println("     |     |");
        System.out.println("     |     |");
        System.out.println("     |_____|");
        System.out.println("  __/       \\__");
        System.out.println(" /             \\");
        System.out.println("/_______________\\");
    }
}
```

### 2. 풀이 [C++]

룩을 이루는 문자 중 이스케이프 처리가 필요한 문자로 역슬래시(`\`)가 있어서 앞에 역슬래시를 붙여 이스케이프 처리만 추가해줬다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << "  ___  ___  ___" << '\n';
    cout << "  | |__| |__| |" << '\n';
    cout << "  |           |" << '\n';
    cout << "   \\_________/" << '\n';
    cout << "    \\_______/" << '\n';
    cout << "     |     |" << '\n';
    cout << "     |     |" << '\n';
    cout << "     |     |" << '\n';
    cout << "     |     |" << '\n';
    cout << "     |_____|" << '\n';
    cout << "  __/       \\__" << '\n';
    cout << " /             \\" << '\n';
    cout << "/_______________\\" << '\n';
}
```
