## 1. 아이디어

<br>

주어진 문자열 S의 i번 글자를 출력하는 문제로 문자열의 인덱스에 주의해서 출력하면 된다.

---

## 2. 코드

<br>

### 1. 풀이 [Java]

Java에서 문자열의 인덱스는 0부터 시작해서 -1을 해줬다.

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        int i = Integer.parseInt(br.readLine());

        System.out.println(s.charAt(i - 1));
    }
}
```

<br>

### 2. 풀이 [C++]

C++에서 문자열의 인덱스는 0부터 시작해서 -1을 해줬다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    int i;
    cin >> s >> i;
    cout << s[i - 1];
}
```
