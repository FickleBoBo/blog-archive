## 1. 아이디어

3월 1일부터 11월 30일까지 모든 꽃이 피어있게 선택하는 최소 개수를 구하는 문제로 그리디 알고리즘을 활용하면 해결할 수 있다. 주어진 꽃들을 피는 날을 기준으로 오름차순 정렬한 우선순위 큐(`pq`)와 현재 피어있는 꽃에 대해 지는 날에 대한 내림차순으로 정렬한 우선순위 큐(`pq2`) 두 개를 활용했다.

현재 날짜를 나타내는 `last`라는 변수를 두어 `pq`에서 현재 피어있는 꽃들을 `pq2`로 옮겼다. 꽃의 개수가 최소가 되게 선택하려면 현재 피어있는 꽃 중에서 가장 늦게 지는 꽃을 선택하면 되므로 `pq2`에서 바로 꺼내면 되며 `pq2`가 비어있다면 두 조건을 만족할 수 없는 상황이다.

`pq2`의 경우 `last` 갱신 후 새로운 꽃이 추가되지 않으면 더 이상 `last`가 커지지 않으므로 이것이 종료 조건이 된다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        PriorityQueue<int[]> pq = new PriorityQueue<>((o1, o2) -> Integer.compare(o1[0], o2[0]));

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            st = new StringTokenizer(br.readLine());
            int sm = Integer.parseInt(st.nextToken());
            int sd = Integer.parseInt(st.nextToken());
            int em = Integer.parseInt(st.nextToken());
            int ed = Integer.parseInt(st.nextToken());

            if (em < 3 || sm == 12) continue;
            pq.offer(new int[]{sm * 100 + sd, em * 100 + ed});
        }

        PriorityQueue<Integer> pq2 = new PriorityQueue<>(Comparator.reverseOrder());
        int last = 301;
        int cnt = 0;
        while (last < 1201) {
            boolean flag = true;
            while (!pq.isEmpty() && pq.peek()[0] <= last) {
                pq2.offer(pq.poll()[1]);
                flag = false;
            }

            if (flag) {
                System.out.println(0);
                return;
            }

            last = pq2.poll();
            cnt++;
        }

        System.out.println(cnt);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;

    int n;
    cin >> n;

    while (n--) {
        int sm, sd, em, ed;
        cin >> sm >> sd >> em >> ed;

        if (em < 3 || sm == 12) continue;
        pq.push({sm * 100 + sd, em * 100 + ed});
    }

    priority_queue<int> pq2;
    int last = 301;
    int cnt = 0;
    while (last < 1201) {
        bool flag = true;
        while (!pq.empty() && pq.top().first <= last) {
            pq2.push(pq.top().second);
            pq.pop();
            flag = false;
        }

        if (flag) {
            cout << 0;
            return 0;
        }

        last = pq2.top();
        pq2.pop();

        cnt++;
    }

    cout << cnt;
}
```
