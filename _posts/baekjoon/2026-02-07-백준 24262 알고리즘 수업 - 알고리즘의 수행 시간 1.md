## 1. 아이디어

MenOfPassion 알고리즘은 $n$ 에 대해 배열에서 $n / 2$ 의 바닥값에 해당하는 인덱스의 값을 반환하는 형태이다. 따라서 `코드1`의 수행 횟수는 $n$ 에 무관하게 $1$ 번이 되며, 시간 복잡도는 $O(1)$ 이라서 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수는 $0$ 이 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(1);
        System.out.println(0);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << 1 << '\n';
    cout << 0 << '\n';
}
```
