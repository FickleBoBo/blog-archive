## 1. 아이디어

$K$ 개의 수 중에서 정확하게 $N$ 개의 수를 뽑아내서 붙였을 때 가장 큰 수를 만들어야 하는 문제로 그리디 알고리즘을 활용하면 해결할 수 있다. 임의의 두 수 $A$, $B$ 가 있을 때, $AB$ 가 $BA$ 보다 크면 $A$ 가 앞에 오게, 작으면 $B$ 가 앞에 오면 된다. 따라서 이 기준에 맞춰 숫자들을 문자열로 다룬 후 정렬을 해줬다. 이 정렬 기준에 맞지 않는 수를 만들 경우 만족하지 않았던 두 수를 위 정렬 기준으로 재배치할 경우 최종 수가 항상 더 크거나 같다는 교환 논증으로 이 경우 최적임을 알 수 있다.

따라서 위 정렬 기준에 맞춘 우선 순위 큐를 먼저 만들어줬다. $K$ 개의 수들에 대해 최소 한 번은 이용해야 하므로 수들을 우선 순위 큐에 넣어줬고, $N - K$ 개의 수들을 추가로 뽑아야 하는데 수의 자릿수가 같다면 위 기준대로 뽑으면 되지만 더 긴 자릿수의 숫자가 존재하면 붙였을 때 자릿수가 더 커지므로, 자릿수를 기준으로 정렬 후, 위 정렬 기준대로 정렬한 수열에서 가장 최선인 수를 $N - K$ 개 뽑아줬다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        String[] arr = new String[n];
        for (int i = 0; i < n; i++) {
            arr[i] = br.readLine();
        }

        PriorityQueue<String> pq = new PriorityQueue<>((o1, o2) -> (o2 + o1).compareTo(o1 + o2));

        for (String s : arr) {
            pq.offer(s);
        }

        Arrays.sort(arr, (o1, o2) -> {
            if (o1.length() != o2.length()) return Integer.compare(o2.length(), o1.length());
            return (o2 + o1).compareTo(o1 + o2);
        });

        for (int i = 0; i < k - n; i++) {
            pq.offer(arr[0]);
        }

        while (!pq.isEmpty()) {
            sb.append(pq.poll());
        }

        System.out.println(sb);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

struct cmp {
    bool operator()(auto& a, auto& b) {
        return a + b < b + a;
    }
};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, k;
    cin >> n >> k;

    vector<string> v(n);
    for (string& s : v) cin >> s;

    priority_queue<string, vector<string>, cmp> pq;

    for (string& s : v) {
        pq.push(s);
    }

    sort(v.begin(), v.end(), [](auto& a, auto& b) {
        if (a.size() != b.size()) return b.size() < a.size();
        return b + a < a + b;
    });

    for (int i = 0; i < k - n; i++) {
        pq.push(v[0]);
    }

    while (!pq.empty()) {
        cout << pq.top();
        pq.pop();
    }
}
```
