## 1. 아이디어

[BaekJoon 9655번 - 돌 게임](/posts/baekjoon-9655) 문제에서 $N$ 의 크기가 매우 커진 문제로 이전 문제는 다이나믹 프로그래밍으로도 해결할 수 있지만 이 문제는 이전 문제처럼 홀짝성을 활용해서 해결해야 한다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        if (n % 2 == 1) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;

    if (n % 2 == 1) {
        cout << "SK";
    } else {
        cout << "CY";
    }
}
```
