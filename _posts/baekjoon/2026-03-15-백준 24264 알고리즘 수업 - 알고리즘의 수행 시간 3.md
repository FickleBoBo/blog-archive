## 1. 아이디어

MenOfPassion 알고리즘은 $n$ 에 대해 배열에서 $1$ 부터 $n$ 까지 반복하는 반복문이 중첩된 형태이다. 따라서 `코드1`의 수행 횟수는 $n^2$ 번이 되며, 시간 복잡도는 $O(N^2)$ 이라서 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수는 $2$ 가 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * n);
        System.out.println(2);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * n << '\n';
    cout << 2 << '\n';
}
```
