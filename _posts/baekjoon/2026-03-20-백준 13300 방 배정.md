## 1. 아이디어

각 학년과 성별 별로 방을 배정할 때 필요한 방의 수를 구하는 문제로 카운팅 배열을 활용하면 해결할 수 있다. 2차원 카운팅 배열로 학년과 성별 별로 인원 수를 세줬고 방의 수는 각 그룹에 대한 몫으로 구할 수 있다. 이때 나머지가 있으면 방을 하나 배정 해줘야 하므로 올림 나눗셈으로 방의 수를 모두 구해서 더해줬다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        int[][] cnt = new int[7][2];
        while (n-- > 0) {
            st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken());
            int y = Integer.parseInt(st.nextToken());
            cnt[y][s]++;
        }

        int ans = 0;
        for (int i = 1; i < 7; i++) {
            for (int j = 0; j < 2; j++) {
                ans += (cnt[i][j] + k - 1) / k;
            }
        }

        System.out.println(ans);
    }
}
```

### 2. 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

int cnt[7][2];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, k;
    cin >> n >> k;

    while (n-- > 0) {
        int s, y;
        cin >> s >> y;
        cnt[y][s]++;
    }

    int ans = 0;
    for (int i = 1; i < 7; i++) {
        for (int j = 0; j < 2; j++) {
            ans += (cnt[i][j] + k - 1) / k;
        }
    }

    cout << ans;
}
```
