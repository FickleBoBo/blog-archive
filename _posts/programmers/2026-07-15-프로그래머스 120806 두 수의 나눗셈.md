## 1. 아이디어

$num1$ 을 $num2$ 로 나눈 값에 $1,000$ 을 곱한 후 정수 부분을 반환하는 문제로 $num1$ 에 $1,000$ 을 먼저 곱한 후 몫을 구하면 간단하게 해결할 수 있다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 * 1000 / num2;
    }
}
```

### 2. 풀이 [C++]

```c++
#include <string>
#include <vector>

using namespace std;

int solution(int num1, int num2) {
    return num1 * 1000 / num2;
}
```
