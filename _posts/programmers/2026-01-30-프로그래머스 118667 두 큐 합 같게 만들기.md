## 1. 아이디어

두 큐에서 각 큐의 원소의 합이 서로 같아지는지 찾는 문제로 각 큐의 합을 미리 구한 후 합이 큰 큐에서 합이 작은 큐로 원소를 이동하는 과정을 반복하면 된다. 이때 각 큐의 원소 합을 같게 만들 수 없는지를 판단해야 하는데 이는 두 큐의 원소의 개수의 합의 두 배만큼만 반복해보면 된다.

1번 큐의 rear와 2번 큐의 front를, 2번 큐의 rear와 1번 큐의 front를 연결한 원형 배열을 상상해보면 배열의 원소의 수는 두 큐의 원소의 수의 합과 같다. 각 연결 지점을 $a$, $b$ 라고 하면 $a$ 와 $b$ 모두 단방향으로 이동하며 이동 후 초기 위치로 돌아오면 다시 처음부터 반복되므로 $a$ 도 원형 배열의 원소의 수만큼, $b$ 도 원형 배열의 원소의 수만큼 최대 이동시키는 것이 상한이다.

## 2. 코드

### 1. 풀이 [Java]

```java
import java.util.*;

class Solution {
    public int solution(int[] queue1, int[] queue2) {
        Queue<Integer> q1 = arrToQueue(queue1);
        Queue<Integer> q2 = arrToQueue(queue2);

        long sum1 = addition(queue1);
        long sum2 = addition(queue2);

        int cnt = 0;
        int max = (q1.size() + q2.size()) * 2;

        while (cnt < max) {
            if (sum1 < sum2) {
                sum1 += q2.peek();
                sum2 -= q2.peek();
                q1.offer(q2.poll());
            } else if (sum1 > sum2) {
                sum1 -= q1.peek();
                sum2 += q1.peek();
                q2.offer(q1.poll());
            } else {
                return cnt;
            }

            cnt++;
        }

        return -1;
    }

    static Queue<Integer> arrToQueue(int[] arr) {
        Queue<Integer> q = new ArrayDeque<>();
        for (int x : arr) {
            q.offer(x);
        }
        return q;
    }

    static long addition(int[] arr) {
        long sum = 0;
        for (int x : arr) {
            sum += x;
        }
        return sum;
    }
}
```

### 2. 풀이 [C++]

```c++
#include <queue>
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> queue1, vector<int> queue2) {
    queue<int> q1;
    queue<int> q2;
    for (int x : queue1) q1.push(x);
    for (int x : queue2) q2.push(x);

    long long sum1 = 0;
    long long sum2 = 0;
    for (int x : queue1) sum1 += x;
    for (int x : queue2) sum2 += x;

    int cnt = 0;
    int mx = (q1.size() + q2.size()) * 2;

    while (cnt < mx) {
        if (sum1 < sum2) {
            sum1 += q2.front();
            sum2 -= q2.front();
            q1.push(q2.front());
            q2.pop();
        } else if (sum1 > sum2) {
            sum1 -= q1.front();
            sum2 += q1.front();
            q2.push(q1.front());
            q1.pop();
        } else {
            return cnt;
        }

        cnt++;
    }

    return -1;
}
```
