## 1. 아이디어

주어진 배열에서 머쓱이의 키 $height$ 보다 큰 키의 개수를 세면 되는 문제로 배열을 한번 순회하며 비교만 해주면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
class Solution {
    public int solution(int[] array, int height) {
        int cnt = 0;

        for (int x : array) {
            if (x > height) cnt++;
        }

        return cnt;
    }
}
```

### 2. 풀이 [C++]

```c++
#include <vector>

using namespace std;

int solution(vector<int> array, int height) {
    int cnt = 0;

    for (int x : array) {
        if (x > height) cnt++;
    }

    return cnt;
}
```
