## 1. 아이디어

다이나믹 프로그래밍을 활용해서 해결할 수 있는 전형적인 문제로 dp 테이블은 해당 가로 길이로 만들 수 있는 타일링의 수로 정의하면 된다. `dp[i]`는 가로 길이 `i`인 타일링의 수로 가로 길이 `i`인 타일링들은 가로 길이 `i - 2`인 타일링들에서 1×2 타일을 오른쪽 끝에 붙이거나, 가로 길이 `i - 1`인 타일링들에서 2×1 타일을 오른쪽에 붙이는 경우가 됨을 알 수 있다. 따라서 `dp[i] = dp[i - 2] + dp[i - 1]`로 점화식을 세울 수 있고, `dp[1] = 1`, `dp[2] = 2`임은 간단하게 알 수 있으니 이를 바탕으로 해결하면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
class Solution {

    static final int MOD = 1_000_000_007;

    public int solution(int n) {
        if (n == 1) return 1;

        int[] dp = new int[1 + n];
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
        }

        return dp[n];
    }
}
```

### 2. 풀이 [C++]

```c++
#include <string>
#include <vector>

using namespace std;

const int MOD = 1000000007;
int dp[60001] = {0, 1, 2};

int solution(int n) {
    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
    }

    return dp[n];
}
```
