## 1. 아이디어

주어진 배열에서 정수 $n$ 의 개수를 세면 되는 문제로 배열을 한번 순회하며 비교만 해주면 된다.

---

## 2. 코드

### 1. 풀이 [Java]

```java
class Solution {
    public int solution(int[] array, int n) {
        int cnt = 0;
        for (int x : array) {
            if (x == n) cnt++;
        }

        return cnt;
    }
}
```

### 2. 풀이 [C++]

`count` 함수로 간단하게 구할 수 있다.

```c++
#include <algorithm>
#include <vector>

using namespace std;

int solution(vector<int> array, int n) {
    return count(array.begin(), array.end(), n);
}
```
