## C. 결정 대기
- **`ans` vs `res`**: `ans`만 17파일 / `res`만 11파일 / **한 파일에 둘 다 쓴 경우 0**. 포스트 내부는 일관하나 전역 승자 없음 → 코퍼스로 도출 불가. 사용자가 정하거나 "둘 다 허용" 확정 필요.

## 자동 판정 금지
- **1회성 이름 ≠ 이탈**: Java 114개 / C++ 87개. 대부분 프로그래머스 도메인 이름(`beverage`, `citations`). 미감사 상태 — 여기 진짜 이탈이 숨어있을 수 있음.
