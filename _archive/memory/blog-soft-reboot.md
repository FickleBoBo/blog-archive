번호 집합 대조에 `comm`을 쓸 때 `sort -n`(숫자정렬)로 정렬해 넣으면 **comm이 사전순을 전제해 결과가 깨짐** → "겹치는 legacy 19개"라는 가짜 수치를 뱉었고, 사용자가 "19는 애매하다"고 직감으로 잡아냄. **번호 집합 교집합은 `awk 'NR==FNR{p[$1]=1;next}($1 in p)'`로 하라.** comm 쓸 거면 양쪽 다 `LC_ALL=C sort`(사전순)로 통일. 검증식이 파일명 날짜(`2025`)를 `grep -oE '[0-9]+'|head -1`로 번호로 오인하는 것도 같은 류 — 번호 추출은 반드시 `grep -oE '백준 [0-9]+'` 앵커.
